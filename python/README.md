# DSA Library - Python

Python implementation of data structures and algorithms.

## Installation

```bash
pip install -e .
```

## Structure

- `src/dsa/` - Main package
  - `ds/` - Data structures
  - `algos/` - Algorithms
  - `math/` - Math utilities
  - `utils/` - Utility functions

## Testing

```bash
pytest
```

## Examples

See `examples/` directory for usage examples.

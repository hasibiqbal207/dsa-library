# DSA Library - JavaScript

JavaScript implementation of data structures and algorithms.

## Installation

```bash
npm install
```

## Structure

- `src/` - Source code
  - `ds/` - Data structures
  - `algos/` - Algorithms
  - `math/` - Math utilities
  - `utils/` - Utility functions

## Testing

```bash
npm test
```

## Examples

See `examples/` directory for usage examples.
